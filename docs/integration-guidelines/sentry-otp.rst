**************************
Sentry OTP Guidelines
**************************

Because of the security reason, All accounts in domain https://sentry.starific.net are required to use 2FA to login, please follow these steps below to setup it

**Step 1:**
Install Google Authenticator https://support.google.com/accounts/answer/1066447

**Step 2:**
Go to User Settings Page and setup 2FA
